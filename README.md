## 🔭 What I care about

- 🔒 **Privacy first:** local processing, encryption at rest, no network at runtime when it is not needed.
- ♿ **Accessible by default:** keyboard flows, contrast checks and tools for people with disabilities.
- 🧪 **Boring, verifiable quality:** strict types, automated tests, documented architecture decisions and security rules.

## ⭐ Featured projects

### 🚗 [lectorPlacasColombia](https://github.com/sergiopon/lectorPlacasColombia)
Local ALPR for Colombian license plates: it detects, tracks and reads vehicles in video **without internet**. The database and crops are encrypted, and anything doubtful is left for human review with a jump to the exact second of the video.

`Python` `ONNX Runtime` `FastAPI` `React` `SQLCipher` `Docker`

### 🆘 [historiaClinicaAlergias](https://github.com/sergiopon/historiaClinicaAlergias)
Mobile emergency medical record read from an **NFC card**: tap the phone and anyone can see blood type, allergies, antidote and emergency contacts. Built as a gift for a person with multiple allergies. This copy is sanitized and uses sample data.

`React` `Vite` `Tailwind CSS v4` `shadcn/ui`
